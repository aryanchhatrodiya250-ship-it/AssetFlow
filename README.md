# AssetFlow

AssetFlow is a full‑stack web application that helps users manage and visualise their financial assets, investments, and related documents.  
The project demonstrates a modern React front‑end (Vite) integrated with a Django/DRF back‑end, and includes Docker support for easy deployment.

---  


## Features
- **Asset Management** – CRUD operations for assets, investments, and documents.  
- **User Authentication** – JWT‑based authentication with Django Rest Framework.  
- **Responsive UI** – Modern React components with a clean, glass‑morphism design.  
- **RESTful API** – Fully documented endpoints for front‑end consumption.  
- **Dockerised** – All services can be spun up with a single `docker-compose up`.  

---  

## Tech Stack
| Layer | Technology |
|-------|------------|
| Front‑end | React, Vite, JavaScript (JSX), CSS (vanilla) |
| Back‑end | Python, Django, Django‑REST‑Framework |
| Database | PostgreSQL (default) |
| Containerisation | Docker, Docker‑Compose |
| Version Control | Git + GitHub |
